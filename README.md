Analisis Sentimen Komentar TikTok tentang Work-Life Balance Menggunakan Algoritma Bi-LSTM dan IndoBERTProyek ini merupakan implementasi sistem analisis sentimen berbasis teks (Text Mining) untuk mengeksplorasi persepsi masyarakat Indonesia di platform media sosial TikTok mengenai isu work-life balance. Sistem ini dibangun menggunakan metodologi CRISP-DM dan membandingkan performa model Deep Learning berbasis sekuensial (Bi-LSTM) dengan model berbasis Transformer (IndoBERT).  📋 OverviewPublic perception tracking regarding work-life balance is still largely performed manually through surveys or direct text screening. This process is time-consuming, highly subjective, and inefficient for large volumes of unstructured data. In social media conditions, a single comment section can also contain numerous text variations of different sentiments, which makes ordinary single-model classification insufficient to capture full contextual nuances.  This research develops and compares sentiment analysis models that can simultaneously capture contextual semantics and classify the public perception of work-life balance in Indonesian text. Two deep learning architectures are trained and compared:  IndoBERT (transformer-based, context-conditioned pre-trained language backbone)  Bi-LSTM (recurrent neural network, forward and backward sequential backbone)  The models are evaluated on the TikTok-WLB comment dataset, which was scraped automatically in April 2026 using Apify. Through data preprocessing, missing value removal, and text duplication filtering, the dataset was refined to highly focused samples. The dataset covers three sentiment classes: negative, neutral, and positive.  The methodology follows the CRISP-DM framework (Business Understanding $\rightarrow$ Data Understanding $\rightarrow$ Data Preparation $\rightarrow$ Modeling $\rightarrow$ Evaluation $\rightarrow$ Deployment). The best-performing model is deployed as an interactive Streamlit web application.  💡 Key FeaturesDual Deep Learning Evaluation: Utilizes and compares two distinct state-of-the-art deep learning architectures, namely IndoBERT (Transformer-based) and Bi-LSTM (Recurrent-based), to analyze semantic contextual layers in Indonesian text.  Dual-Direction Context Tracking: The Bi-LSTM implementation processes text input simultaneously in both forward and backward directions to maintain sequential word dependencies.  Simultaneous Contextual Attention: Powered by IndoBERT's self-attention mechanism, allowing the system to comprehend complex word relationships and casual text structures concurrently across the entire sentence.  Automated Data Gathering Pipeline: Integrated with Apify and Python libraries to systematically scrape, collect, and extract large volumes of social media comment datasets on-the-fly based on specific keywords.  Structured Mining Standard: Developed strictly under the partial CRISP-DM framework, ensuring a highly organized data pipeline from initial business understanding up to final model deployment.  Three-Class Sentiment Granularity: Effectively classifies public perception into three distinct sentiment dimensions: positive, neutral, and negative.  High-Accuracy Performance: IndoBERT model achieves state-of-the-art results for the specific dataset with a macro F1-score of 93.93% and an overall accuracy of 96.35%.  Interactive Web Deployment: Deployed as a fully functional and user-friendly web application using Streamlit, allowing users to perform sentiment predictions interactively via manual text inputs or automated CSV uploads.  🎯 Key ContributionsComparative Indonesian NLP Benchmarking: Provides a rigorous and direct comparative analysis between a Transformer-based model (IndoBERT) and a Recurrent-based model (Bi-LSTM) tailored specifically for understanding casual and informal Indonesian text structures on social media.  Public Sentiment Landscape on Work-Life Balance: Delivers an empirical mapping of public perception regarding work-life balance in Indonesia, revealing that a significant majority (59.13%) of digital discourse expresses negative sentiment driven by workload and work environments.  Structured CRISP-DM Text Mining Implementation: Demonstrates a systematic methodology using the CRISP-DM framework to transform large volumes of unstructured, raw social media comments into a highly refined and clean dataset for advanced deep learning tasks.  State-of-the-Art Indonesian Text Classification: Establishes a high-performing baseline for social media sentiment classification using the context-conditioned IndoBERT architecture, achieving an outstanding accuracy of 96.35% and a macro F1-score of 93.93%.  Practical Decision-Support Deployment: Bridges the gap between academic modeling and real-world application by deploying the optimal model into an interactive Streamlit web interface, providing human resource professionals and policymakers with an accessible tool to monitor employee well-being trends interactively.  🚀 Installation & SetupRequirementsPython: Version 3.8 or higher.
